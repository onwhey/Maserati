# Structure v2 证据矩阵

## 1. 文档定位

本文档用于把 Structure v2 的“结构语义”拆成可落地的证据清单。

它回答三个问题：

```text
每一种结构状态，需要哪些客观证据支撑；
这些证据里，哪些已经由现有结构特征和原子信号覆盖；
哪些还需要后续补 Feature / AtomicSignal。
```

本文档不负责：

```text
修改代码；
修改数据库；
修改 MarketRegime；
修改 StrategyRouting；
修改 StrategyDefinition；
决定开仓、平仓、加仓、减仓；
决定目标仓位；
决定订单计划；
访问 Binance；
执行真实交易。
```

Structure v2 的目标不是预测未来，而是把“当下已经能观察到的结构事实”描述清楚。

例如：

```text
不说：顶部已经确认；
而说：多头高位结构受压。

不说：熊市已经开始；
而说：多头结构破坏候选 / 多头结构已破坏。

不说：底部已经确认；
而说：空头低位结构受压 / 空头结构修复候选。
```

## 2. 现有能力盘点

### 2.1 已有特征可以复用

当前 Structure v1 已经具备以下基础事实：

```text
1d 大结构支撑区；
1d 大结构压力区；
4h 小结构支撑区；
4h 小结构压力区；
当前价格距离支撑区的距离；
当前价格距离压力区的距离；
当前价格在支撑压力区间中的位置；
支撑区触碰次数；
压力区触碰次数；
支撑区有效性评分；
压力区有效性评分；
区间宽度；
向上突破压力区的幅度；
向下跌破支撑区的幅度。
```

这些足够回答“价格现在在哪里”和“一根已收盘 K 线是否发生突破 / 跌破”。

### 2.2 已有原子信号可以复用

当前 Structure v1 已经具备以下原子判断：

```text
是否靠近 1d 大支撑；
是否靠近 1d 大压力；
是否处于 1d 大区间中部 / 上半部 / 下半部；
是否靠近 4h 小支撑；
是否靠近 4h 小压力；
是否处于 4h 小区间中部 / 上半部 / 下半部；
支撑区是否具备基本有效性；
压力区是否具备基本有效性；
区间结构是否具备基本可解释性；
是否向上突破压力区；
是否向下跌破支撑区；
结构证据是否不明确。
```

这些可以作为 Structure v2 的第一层证据。

## 3. 当前缺口

Structure v2 如果要从“位置描述”升级到“结构状态”，还缺少几类证据。

### 3.1 结构连续性证据

需要知道：

```text
当前结构是否仍然保持；
关键支撑是否还守住；
关键压力是否还压住；
回调是否跌破了更重要的低点；
反弹是否突破了更重要的高点。
```

这类证据用于区分：

```text
普通回调；
高位结构受压；
结构破坏候选；
结构已破坏。
```

### 3.2 收回与假突破证据

需要知道：

```text
跌破后是否快速收回；
突破后是否快速跌回；
跌破是否只是短暂刺破；
突破是否只是短暂冲高。
```

这类证据用于避免把“一根 K 线刺破”过早写成“结构已破坏”。

### 3.3 反抽 / 回踩确认证据

需要知道：

```text
跌破支撑后，反抽到原支撑附近是否失败；
突破压力后，回踩到原压力附近是否有效；
原支撑是否开始表现为压力；
原压力是否开始表现为支撑。
```

这类证据用于区分：

```text
结构破坏候选；
结构已破坏；
结构修复候选；
结构已修复。
```

### 3.4 确认次数与持续性证据

需要知道：

```text
是单根 K 线触发，还是连续多根 K 线确认；
跌破 / 突破后经过了多少个已收盘周期；
结构状态是否已经延续，还是刚刚出现。
```

这类证据用于避免 Structure v2 过度敏感。

### 3.5 历史大结构参考位证据

需要知道：

```text
某个价格带是否曾经长期具备支撑或压力参考意义；
它是否横跨了大量 1d K 线仍然被多次测试；
它是否在触碰后出现过有效反应；
当前价格重新靠近该参考位时，它更像长周期支撑还是长周期压力；
当前价格是否已经明显远离该参考位。
```

这类证据用于提醒系统：某些位置虽然一年未必触碰几次，但一旦靠近，可能具有长周期支撑压力参考意义。

它不是一根精确线，而应该是一个价格带。

示例：

```text
历史大结构参考位：约 56,850 ~ 73,300；
当前角色：更像长周期支撑；
解释：价格靠近该区域时，需要关注支撑反应，但该事实本身不代表应该做多。
```

这类证据不能直接推出交易动作。

它只能告诉下游：

```text
当前价格正在接近一个历史大结构参考位；
这个价格带曾经对市场有长期支撑或压力意义；
如果重新接近、进入、失守或远离，结构解释时应该把它作为补充证据。
```

## 4. Structure v2 证据矩阵

| 结构状态 | 直白含义 | 可以复用的 v1 证据 | 需要补充的证据 | 验收重点 |
|---|---|---|---|---|
| 多头结构保持 | 上涨结构还没有被破坏 | 价格在关键支撑上方；支撑有效；没有明显跌破大支撑 | 更高低点是否仍然保持；回调是否仍在合理范围内 | 不能因为 4h 小回调就说大结构坏了 |
| 多头高位结构受压 | 上涨背景还在，但高位推进遇到压力 | 靠近压力；压力有效；区间上半部；冲高未突破 | 多次冲高失败；历史大压力区是否仍有效；动能不足时是否仍未跌破关键支撑 | 不能写成顶部确认，也不能写成熊市开始 |
| 多头结构破坏候选 | 关键支撑刚被破坏，但还缺确认 | 向下跌破支撑；支撑有效性存在 | 是否只是短暂刺破；是否快速收回；是否只有单根 K 线 | 不能一根跌破就直接写成已破坏 |
| 多头结构已破坏 | 上涨结构已经失效 | 跌破关键支撑；不再处于有效支撑上方 | 跌破后未快速收回；反抽原支撑失败；原支撑转压力；历史支撑区失守 | 仍然不能输出做空或平多动作 |
| 多头结构修复 | 此前受压或破坏的结构被重新收回 | 向上突破压力；重新站回关键区间 | 收回关键支撑；回踩有效；原压力转支撑；历史压力区被重新站上 | 不能写成必须做多，只能写结构修复 |
| 空头结构保持 | 下跌结构还没有被修复 | 价格在关键压力下方；压力有效；没有明显突破大压力 | 更低高点是否仍然保持；反弹是否仍在合理范围内 | 不能因为 4h 小反弹就说大结构修复 |
| 空头低位结构受压 | 下跌背景还在，但低位继续下跌遇到支撑 | 靠近支撑；支撑有效；区间下半部；下探未跌破 | 多次下探失败；历史大支撑区是否仍有效；下跌动能不足时是否仍未突破关键压力 | 不能写成底部确认，也不能写成牛市开始 |
| 空头结构修复候选 | 关键压力刚被突破，但还缺确认 | 向上突破压力；压力有效性存在 | 是否只是短暂冲高；是否快速跌回；是否只有单根 K 线 | 不能一根突破就直接写成已修复 |
| 空头结构已修复 | 下跌结构已经失效 | 突破关键压力；不再处于有效压力下方 | 突破后未快速跌回；回踩原压力有效；原压力转支撑；历史压力区被重新站上 | 仍然不能输出做多或平空动作 |
| 空头结构重新转弱 | 此前修复候选或修复后的结构再次走弱 | 重新跌破支撑；靠近压力失败 | 跌回关键区间；反弹失败；原支撑再次失效；历史压力区压制重新有效 | 不能写成必须做空，只能写结构重新转弱 |

## 5. Feature 缺口清单

后续如需真正实现 Structure v2，建议优先补以下 FeatureDefinition。

### 5.1 结构连续性特征

```text
上一重要低点；
上一重要高点；
当前价格相对上一重要低点的距离；
当前价格相对上一重要高点的距离；
更高低点是否保持；
更低高点是否保持。
```

### 5.2 收回 / 跌回特征

```text
跌破支撑后是否在限定周期内收回；
突破压力后是否在限定周期内跌回；
跌破后经过的已收盘周期数量；
突破后经过的已收盘周期数量；
收回后的站稳周期数量；
跌回后的压制周期数量。
```

### 5.3 反抽 / 回踩特征

```text
跌破支撑后反抽原支撑是否失败；
突破压力后回踩原压力是否有效；
原支撑是否转化为压力；
原压力是否转化为支撑；
反抽或回踩距离关键区间的偏离幅度。
```

### 5.4 噪声过滤特征

```text
突破 / 跌破幅度是否超过固定比例阈值；
突破 / 跌破幅度是否超过 ATR 标准化阈值；
是否只是影线刺破；
是否是收盘价确认；
是否连续多个已收盘周期确认。
```

### 5.5 历史大结构区特征

```text
历史大区间上沿；
历史大区间下沿；
历史大结构区形成时覆盖的 1d K 线数量；
历史大结构区被测试的次数；
历史大结构区最近一次有效反应时间；
历史大结构区最近一次有效反应幅度；
历史压力区突破后是否曾转为支撑；
历史支撑区跌破后是否曾转为压力；
当前价格距离历史大结构区的距离；
历史大结构区当前更像支撑、压力，还是失效区。
```

历史大结构区必须表达为价格带，不得表达为单点价格。

## 6. AtomicSignal 缺口清单

后续如需实现 Structure v2，建议新增或升级以下原子信号。

```text
大结构支撑守住；
大结构压力压住；
小结构支撑守住；
小结构压力压住；

大结构支撑跌破候选；
大结构支撑跌破确认；
小结构支撑跌破候选；
小结构支撑跌破确认；

大结构压力突破候选；
大结构压力突破确认；
小结构压力突破候选；
小结构压力突破确认；

跌破后快速收回；
突破后快速跌回；
跌破后反抽失败；
突破后回踩有效；

原支撑转压力；
原压力转支撑；

历史大压力区有效；
历史大支撑区有效；
历史压力转支撑；
历史支撑转压力；
当前价格靠近历史大结构区。
```

这些原子信号仍然只回答“条件是否成立”，不得输出任何交易动作。

## 7. 推荐落地顺序

### 7.1 第一阶段：用现有证据先做粗版 Structure v2

先只复用现有支撑、压力、区间位置、突破、跌破证据，形成粗粒度结构语义。

目的：

```text
验证 Structure v2 的输出形式是否清楚；
验证 MarketRegime 消费 Structure v2 后是否更容易解释；
验证后台复盘是否能看懂结构状态。
```

这一阶段允许结论偏保守，但必须明确标记证据不足。

### 7.2 第二阶段：补历史大结构区、收回、反抽、回踩、角色互换证据

补齐后，Structure v2 才能更可靠地区分：

```text
刺破；
真实跌破；
突破失败；
突破有效；
支撑仍有效；
支撑已经失效；
压力仍有效；
压力已经失效；
历史大压力是否仍然有效；
历史大支撑是否仍然有效；
历史压力是否已经转为支撑；
历史支撑是否已经转为压力。
```

### 7.3 第三阶段：MarketRegime 消费 Structure v2

MarketRegime 不再临时猜测结构是否破坏。

它只消费 Structure v2 已经给出的结构事实，再结合趋势、动能、波动、市场大背景和风险状态，识别市场环境。

## 8. 明确禁止

禁止：

```text
为了让某段回测收益变好而反推结构状态；
用未来 K 线确认当前结构状态；
把“多头高位结构受压”写成“顶部已确认”；
把“空头低位结构受压”写成“底部已确认”；
把支撑压力证据隐藏掉，只输出一个结构状态；
把历史大结构区简化成一根精确价格线；
让 Structure DomainSignal 读取 Kline；
让 Structure DomainSignal 读取 FeatureValue；
让 Structure DomainSignal 重算支撑压力；
让 Structure DomainSignal 输出目标仓位；
让 Structure DomainSignal 输出订单动作。
```

## 9. 本阶段结论

当前不建议从头推翻 Feature / AtomicSignal / DomainSignal。

更合理的路线是：

```text
先保留现有支撑压力体系；
再补历史大结构区、结构连续性、收回、反抽、回踩和角色互换证据；
最后让 Structure v2 在这些证据之上输出结构语义。
```

也就是说，Structure v2 不是重做一套新系统，而是在现有结构事实上补上“结构状态解释层”。
