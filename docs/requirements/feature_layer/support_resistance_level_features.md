# 支撑压力识别算法需求说明

## 1. 文档目的

本文定义 Structure 领域所需的“支撑 / 压力位”识别口径。

这份文档要解决的核心问题是：系统不能把一个过宽的历史价格区间直接当成支撑或压力。支撑压力应当来自市场已经验证过的局部拐点，并且要能解释为“价格曾在这里发生过有效反应”。

当前已发现的问题：

- 旧算法可能输出过宽区间，例如 `71522 - 78228` 这类连续多日都难以走完的范围。
- 过宽区间会让系统误以为价格仍在支撑内，从而误导 Structure、MarketRegime 和后续策略。
- 旧口径更像“历史大区间参考”，不适合作为正式的支撑压力线。

新口径要求：

- 支撑压力必须来自有效局部低点 / 高点。
- 支撑压力是“窄区域”，不是宽泛历史区间。
- 每次计算只能使用当时已经收盘的数据，禁止后视镜。
- 特征层只输出市场结构事实，不生成交易动作。

## 2. 职责边界

本算法属于 FeatureLayer / Structure 相关特征。

负责：

- 从已收盘 K 线中识别有效局部低点和局部高点。
- 把相近的有效低点 / 高点聚合成支撑区或压力区。
- 判断当前价格与支撑 / 压力区的关系。
- 输出可供 AtomicSignal 消费的结构特征。

不负责：

- 不判断应该做多还是做空。
- 不生成策略信号。
- 不生成目标仓位。
- 不生成订单动作。
- 不访问账户、持仓、订单、成交。
- 不访问 Binance。
- 不访问 Redis。
- 不调用大模型。
- 不发送 Hermes。
- 不涉及真实交易。

## 3. 基本定义

### 3.1 支撑点

支撑点不是任意低点，而是满足以下条件的局部低点：

1. 它是过去一段已收盘 K 线中的局部低点。
2. 低点之后价格出现了足够幅度的反弹。
3. 该低点与相邻有效低点之间有足够时间间隔，避免把同一段震荡里的毛刺重复计算。

直白说：价格跌到这里后，市场真的反弹过，这个低点才有资格成为支撑参考。

### 3.2 压力点

压力点不是任意高点，而是满足以下条件的局部高点：

1. 它是过去一段已收盘 K 线中的局部高点。
2. 高点之后价格出现了足够幅度的回落。
3. 该高点与相邻有效高点之间有足够时间间隔，避免把同一段震荡里的毛刺重复计算。

直白说：价格涨到这里后，市场真的跌回来过，这个高点才有资格成为压力参考。

### 3.3 支撑区 / 压力区

支撑压力不是一条精确价格线，而是一个窄区域。

但这个区域必须有宽度上限。超过宽度上限时，不能强行把它当成一个支撑 / 压力区，应当拆分成多个子区域，或者直接放弃该区域。

### 3.4 历史大区间

历史大区间不是正式支撑 / 压力位。

它可以作为可选参考证据，用来提醒：

> 当前价格靠近一个长期历史交易密集区或大级别区间边界。

但它不能替代正式支撑 / 压力识别，也不能直接输出“支撑守住”或“压力压住”。

## 4. 数据使用规则

### 4.1 时间规则

所有计算必须使用 UTC 已收盘 K 线。

在某个分析周期 `T` 上运行时：

- 可以使用 `T` 及之前已经收盘的 K 线来判断当前价格位置。
- 识别历史支撑 / 压力时，不能使用 `T` 之后的数据。
- 局部拐点确认需要右侧 K 线时，只能确认已经有足够右侧已收盘 K 线的历史拐点。

### 4.2 禁止后视镜

不能因为未来价格涨回去了，就把当时的下跌定义为“回调”。

也不能因为未来价格跌下去了，就把当时的下跌定义为“熊市开始”。

系统在当时只能回答：

- 当前结构有没有被破坏？
- 当前是否靠近有效支撑？
- 当前是否靠近有效压力？
- 当前支撑 / 压力是否正在被测试？
- 当前支撑 / 压力是否出现突破或跌破候选？

## 5. 初始算法参数

以下参数是 P0 默认值，后续可以通过版本化算法调整。

| 参数 | 1d 默认值 | 4h 默认值 | 说明 |
|---|---:|---:|---|
| 局部极值左侧 K 数 | 3 | 3 | 当前点低于 / 高于左侧 N 根 K 线 |
| 局部极值右侧 K 数 | 3 | 3 | 当前点低于 / 高于右侧 N 根已收盘 K 线 |
| 反应确认窗口 | 10 根 | 12 根 | 拐点之后观察多少根 K 线确认反弹 / 回落 |
| 有效反应幅度 | `max(2 × ATR14, 3%)` | `max(1.5 × ATR14, 1.2%)` | 防止微小反弹被误认为有效支撑 |
| 最小时间间隔 | 10 根 | 12 根 | 防止同一段震荡内重复记点 |
| 聚类容忍距离 | `max(0.8 × ATR14, 1%)` | `max(0.6 × ATR14, 0.5%)` | 相近拐点可以合并成一个区域 |
| 区域最大宽度 | `min(1.5 × ATR14, 4%)` | `min(1.2 × ATR14, 2%)` | 超过上限则拆分或放弃 |
| 区域最小宽度 | `max(0.3 × ATR14, 0.5%)` | `max(0.25 × ATR14, 0.3%)` | 防止区域过窄导致毛刺频繁穿透 |
| 活跃区域最少触碰次数 | 2 | 2 | 一次触碰只能算候选区，不能直接算强支撑 / 强压力 |
| 有效突破 / 跌破确认 | 连续 2 根收盘确认 | 连续 2 根收盘确认 | 防止单根插针误判 |
| 失效确认 | 连续 3 根未收复 | 连续 3 根未收复 | 支撑 / 压力失效后不再继续作为同角色参考 |

说明：

- ATR 使用同周期 ATR14。
- 百分比均以当前结构区核心价或当前收盘价为基准，具体实现需保持一致。
- 如果 ATR 和百分比条件冲突，优先使用更严格的条件。

## 6. 识别流程

### 6.1 选择回看窗口

系统按周期分别计算：

- 1d：默认回看 365 根；必要时可扩展 720 根作为长期参考。
- 4h：默认回看 120 根；必要时可扩展 240 根作为短中期参考。

720 天大结构只作为可选长期参考，不应自动替代正式支撑压力算法。

### 6.2 找局部低点和局部高点

支撑候选点：

- 当前低点低于左侧 N 根 K 线低点；
- 当前低点低于右侧 N 根已收盘 K 线低点；
- 后续确认窗口内出现足够幅度反弹。

压力候选点：

- 当前高点高于左侧 N 根 K 线高点；
- 当前高点高于右侧 N 根已收盘 K 线高点；
- 后续确认窗口内出现足够幅度回落。

### 6.3 过滤无效拐点

以下拐点应过滤：

- 反弹 / 回落幅度不足。
- 与相邻有效拐点时间间隔太近。
- 只是一根极端插针，后续没有有效反应。
- 成交和波动异常导致的孤立毛刺。当前系统尚未完整使用成交量时，至少应通过 ATR 和后续反应过滤。

### 6.4 聚合成支撑 / 压力区

相近的有效低点可以聚合成支撑区。

相近的有效高点可以聚合成压力区。

每个区域至少包含：

- 核心价格；
- 下沿；
- 上沿；
- 区域宽度；
- 来源拐点数量；
- 最近触碰时间；
- 触碰次数；
- 时间周期；
- 强度评分；
- 当前状态。

如果多个拐点距离太远，不能强行合并成一个大区间。

## 7. 区域状态

每个支撑 / 压力区应具备状态。

| 状态 | 含义 |
|---|---|
| 候选 | 有一个有效拐点，但触碰次数或验证强度不足 |
| 有效 | 已经被至少两次有效触碰或验证 |
| 测试中 | 当前价格进入该区域，正在测试支撑 / 压力 |
| 跌破候选 | 价格收盘跌破支撑区，但尚未满足确认条件 |
| 突破候选 | 价格收盘突破压力区，但尚未满足确认条件 |
| 已确认跌破 | 支撑区被连续收盘确认跌破 |
| 已确认突破 | 压力区被连续收盘确认突破 |
| 已失效 | 支撑 / 压力被穿透且未能收复，不再作为同角色参考 |
| 角色转换 | 原压力突破后转为支撑，或原支撑跌破后转为压力 |

## 8. 角色转换规则

### 8.1 压力转支撑

满足以下条件时，压力区可以转换为支撑区：

1. 价格连续 2 根 K 线收盘站上压力区上沿。
2. 突破幅度达到确认阈值。
3. 后续回踩该区域时没有重新跌回区域下方。

### 8.2 支撑转压力

满足以下条件时，支撑区可以转换为压力区：

1. 价格连续 2 根 K 线收盘跌破支撑区下沿。
2. 跌破幅度达到确认阈值。
3. 后续回抽该区域时没有重新站回区域上方。

### 8.3 转换不是永久的

角色转换后，如果价格再次反向有效突破，该区域可以重新转换。

系统不能把某个历史支撑 / 压力永久固化。

## 9. 强度评分

支撑 / 压力强度应由多个因素共同决定。

推荐评分因子：

- 触碰次数；
- 每次触碰后的反应幅度；
- 最近触碰时间；
- 所属周期；
- 是否发生过角色转换；
- 区域宽度惩罚；
- 是否处于当前价格附近。

直观规则：

- 触碰越多，强度越高。
- 反应越强，强度越高。
- 时间越近，权重越高。
- 大周期结构位权重高于小周期结构位。
- 区域越宽，可信度越低。
- 过久远但近期从未响应的结构位，应逐步衰减。

## 10. 输出契约

FeatureLayer 输出应尽量简洁，不保存完整 K 线数组。

推荐输出字段：

```text
nearest_support_zone
nearest_resistance_zone
active_support_zones
active_resistance_zones
current_price_position
inside_zone
support_distance_pct
support_distance_atr
resistance_distance_pct
resistance_distance_atr
support_status
resistance_status
structure_reference_quality
no_zone_reason
```

每个 zone 推荐包含：

```text
role
status
timeframe
core_price
lower
upper
width_pct
strength
touch_count
last_touched_at_utc
distance_pct
distance_atr
source_pivot_count
source_summary
```

禁止输出：

- 完整历史 K 线数组；
- 完整指标序列；
- 不可控长 JSON；
- 直接交易建议；
- 目标仓位；
- 订单动作。

## 11. 原子信号消费建议

AtomicSignal 可以基于该特征形成以下原子事实：

- 靠近支撑；
- 靠近压力；
- 支撑测试中；
- 压力测试中；
- 支撑守住；
- 压力压住；
- 支撑跌破候选；
- 压力突破候选；
- 支撑确认跌破；
- 压力确认突破；
- 支撑转压力；
- 压力转支撑；
- 无有效支撑压力参考；
- 支撑压力夹层 / 区间压缩。

注意：

- 价格只是位于支撑上方，不等于“支撑守住”。
- 价格只是位于压力下方，不等于“压力压住”。
- “守住 / 压住”必须有触碰、测试和反应证据。

## 12. DomainSignal 消费建议

Structure DomainSignal 应表达结构事实，而不是单一方向结论。

当支撑和压力同时存在时，不应强行压缩成“支撑守住”或“压力压住”一个结论。

更合理的表达是：

```text
当前价格处于支撑与压力之间；
下方存在有效支撑；
上方存在有效压力；
当前更接近哪一侧；
哪一侧正在被测试；
是否出现突破 / 跌破候选。
```

## 13. MarketRegime 消费建议

MarketRegime 可以消费 Structure 的事实，但不得让 Structure 直接替代市场环境判断。

合理用法：

- 多头环境中，价格回踩有效支撑且支撑未破，说明多头结构仍有支撑证据。
- 多头环境中，关键支撑确认跌破，说明多头结构开始受损。
- 空头环境中，价格反弹到有效压力且压力未破，说明空头结构仍有压力证据。
- 空头环境中，关键压力确认突破，说明空头结构开始受损。
- 支撑压力同时存在时，应考虑区间震荡、夹层、压缩，而不是强行判断趋势延续。

## 14. 验收样本

### 14.1 过宽区间样本

样本：

```text
2026-05-10
2026-05-16
2026-05-27
```

验收重点：

- 不应输出类似 `71522 - 78228` 这种过宽支撑区。
- 如果历史区间确实存在，只能作为“历史大区间参考”，不能作为正式支撑。
- 页面说明不能让用户误以为这是一条可直接交易的支撑线。

### 14.2 历史区间顶部转支撑样本

样本：

```text
2025-04-08 附近
```

验收重点：

- 系统只能使用当时已经收盘的数据。
- 如果识别前期震荡区间顶部成为支撑，必须能说明来源拐点和角色转换依据。
- 不能因为未来继续上涨，就倒推当时一定是支撑。

### 14.3 高位结构受压样本

样本：

```text
2025-10-15 → 2025-11-02
```

验收重点：

- 系统应识别价格是否靠近或跌破关键结构位。
- 如果只是顶部回落，但尚未确认结构破坏，应表达为结构受压或测试中，而不是直接预测熊市。

### 14.4 普通震荡样本

验收重点：

- 不应在普通震荡中生成过多“强支撑 / 强压力”。
- 当支撑与压力距离较近时，应能表达区间夹层或压缩。

## 15. 通过标准

满足以下条件才算通过：

- 没有后视镜数据泄漏。
- 支撑 / 压力来自有效局部拐点，而不是宽泛历史区间。
- 支撑 / 压力区域宽度受控。
- 支撑 / 压力状态可解释。
- 角色转换有明确确认条件。
- 支撑失效后不会继续被当成同角色有效支撑。
- 压力失效后不会继续被当成同角色有效压力。
- Structure 页面能解释关键区间来源。
- MarketRegime 消费 Structure 时不会把“参考区间”误当成“确定趋势”。

## 16. 失败标准

出现以下情况视为失败：

- 输出过宽支撑 / 压力区。
- 只因为价格在某区间上方，就说支撑守住。
- 只因为价格在某区间下方，就说压力压住。
- 用未来走势确认历史支撑压力。
- 把历史大区间直接当成正式支撑压力。
- 支撑 / 压力失效后仍长期保留为同角色强证据。
- 支撑和压力同时存在时，强行只输出单边结论。
