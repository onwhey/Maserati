# Structure Domain Signals v2

## 1. 文档定位

本文档定义 `structure` 领域第二版领域聚合规则的需求草案。

v2 不推翻 v1。

v2 的核心变化是：

```text
v1 主要回答：价格现在在哪？
v2 进一步回答：这个位置对当前结构意味着什么？
```

也就是说，v2 不删除支撑压力、区间位置、突破、跌破这些事实。

相反，v2 要保留这些事实，并在它们之上增加一层结构语义：

```text
结构保持；
结构受压；
结构破坏候选；
结构已破坏；
结构修复。
```

本文档回答：

```text
Structure v1 和 v2 的区别是什么；
原有支撑压力事实如何保留；
结构保持、结构受压、结构破坏、结构修复分别是什么意思；
MarketRegime 应如何消费这些结构事实；
哪些判断仍然不属于 Structure DomainSignal。
```

本文档不负责：

```text
修改 FeatureLayer；
修改 AtomicSignal；
实现 MarketRegime；
选择 StrategyDefinition；
生成 StrategySignal；
生成 DecisionSnapshot；
决定目标仓位；
决定是否开仓、平仓、加仓或减仓；
决定订单计划；
访问 Binance；
执行真实交易。
```

正式运行时不读取 Markdown 文件；本文档只定义需求和验收口径。

配套证据矩阵：

```text
docs/plans/structure_v2_evidence_matrix.md
```

该矩阵用于说明每一种结构状态需要哪些特征、原子信号和证据支撑；如果后续编码时发现证据不足，应先补 Feature / AtomicSignal 需求，再实现 Structure v2。

## 2. v1 与 v2 的核心区别

### 2.1 v1：位置描述

Structure v1 更像是在描述：

```text
价格现在处在支撑附近；
价格现在处在压力附近；
价格现在处在区间上半部；
价格现在处在区间下半部；
价格向上突破；
价格向下跌破；
1d 大结构和 4h 小结构是否一致。
```

它的重点是“位置”和“当前形态”。

示例：

```text
1d 大结构靠近支撑；
4h 小结构跌破小支撑；
当前价格处于大区间下半部。
```

### 2.2 v2：结构语义

Structure v2 在 v1 的位置事实上继续判断：

```text
这个支撑是否还守住了结构；
这个压力是否已经让高位结构受压；
这个跌破只是候选，还是已经确认破坏；
这个收回只是反抽，还是结构修复；
这个区间位置对大结构意味着保持、受压、破坏还是修复。
```

它的重点是“结构状态”。

示例：

```text
价格靠近支撑，并且支撑尚未失效
→ 多头结构保持。

价格在高位压力区多次失败，动能减弱，但关键支撑尚未破坏
→ 多头高位结构受压。

价格跌破关键支撑，但尚未确认延续
→ 多头结构破坏候选。

价格跌破关键支撑后，反抽失败并继续走弱
→ 多头结构已破坏。

价格跌破后重新收回关键结构，并站稳
→ 多头结构修复。
```

## 3. 原有支撑压力如何处理

原有支撑压力不删除、不降级、不隐藏。

v2 必须继续保留 v1 的以下事实：

```text
1d 大结构支撑区；
1d 大结构压力区；
4h 小结构支撑区；
4h 小结构压力区；
当前价格距离支撑的距离；
当前价格距离压力的距离；
当前价格在区间中的位置；
支撑 / 压力触碰次数；
向上突破事实；
向下跌破事实；
大结构与小结构是否一致。
```

v2 的新增语义必须建立在这些事实之上。

换句话说：

```text
支撑压力 = 结构语义的证据；
结构保持 / 受压 / 破坏 / 修复 = 对这些证据的领域级解释。
```

禁止把支撑压力字段删除后只输出一句“结构已破坏”。

人工复盘必须仍然能看到：

```text
是哪个支撑；
是哪个压力；
价格距离支撑压力多远；
是 1d 大结构还是 4h 小结构；
是第一次触碰，还是多次测试；
是刚刚跌破，还是跌破后反抽失败。
```

### 3.1 历史大结构参考位

Structure v2 需要补充“历史大结构参考位”表达。

这里的历史大结构参考位，本质仍然是支撑压力事实，只是观察周期更长、出现频率更低、参考权重更高。

它的作用不是重新发明一套箱体系统，也不是直接改写 MarketRegime，而是像人工看盘时的提醒：

```text
这里附近有一个一年级别或更长周期的历史结构位；
这个位置历史上可能形成过支撑；
这个位置历史上可能形成过压力；
价格重新靠近这里时，需要把它作为长期结构参考。
```

历史大结构参考位必须表达为价格带，不得表达为单点价格。

例如：

```text
历史大结构参考位：56,850 ~ 73,300；
不要写成：支撑线 = 56,854.67。
```

Structure v2 输出历史大结构参考位时，必须保留证据：

```text
参考位上下沿；
来源类型；
覆盖了多少根 1d K 线；
历史上被测试过多少次；
触碰后是否出现过有效反应；
当前更像长周期支撑，还是长周期压力；
当前价格是否接近、远离，或处于角色互换观察位置。
```

历史大结构参考位只作为 structure 领域的补充证据。

它不得单独决定：

```text
structure 方向；
MarketRegime；
StrategyRouting；
StrategySignal；
DecisionSnapshot；
目标仓位；
订单动作。
```

禁止：

```text
因为靠近历史大支撑就写成应该做多；
因为靠近历史大压力就写成应该做空；
因为历史参考位有效就写成牛市或熊市确认；
因为价格远离历史参考位就写成没有结构风险。
```

正确表达方式：

```text
上方存在有效的长周期历史压力参考位；
下方存在有效的长周期历史支撑参考位；
当前价格接近长周期历史结构参考位；
当前价格明显远离长周期历史结构参考位；
当前价格处于历史参考位附近，存在支撑压力角色互换观察价值。
```

## 4. 输入边界

Structure v2 仍然只能读取同一 AtomicSignalSet 中、归属于 `structure` 领域、且被当前 StrategyAnalysisRelease 选中的 AtomicSignalValue。

不得读取：

```text
FeatureValue；
Kline；
MarketSnapshot 原始行情；
其他领域的 AtomicSignalValue；
其他 DomainSignalValue；
MarketRegimeSnapshot；
StrategyRouteDecision；
StrategySignal；
DecisionSnapshot；
账户、持仓、订单或成交；
Binance；
DeepSeek。
```

如果 v2 需要新的结构证据，必须先补充 AtomicSignal requirements。

如果新的结构证据需要新的基础数值，必须先补充 FeatureLayer requirements。

Structure v2 不得为了判断结构破坏而临时读取 K 线或重算指标。

## 5. 输出模式

Structure v2 仍然输出一份 `structure` DomainSignalValue。

这份输出应同时包含两层信息：

```text
第一层：v1 已有的位置事实；
第二层：v2 新增的结构语义。
```

建议输出结构包含：

```text
major_structure = 1d 大结构位置事实；
minor_structure = 4h 小结构位置事实；
historical_major_reference = 长周期历史支撑压力参考位；
structure_state = 综合结构语义；
structure_state_reason = 结构语义形成原因；
structure_state_evidence = 使用了哪些支撑、压力、突破、跌破、收回、反抽失败证据。
```

`direction` 仍然不能被 4h 小结构单独决定。

v2 可以让 4h 表达：

```text
短周期开始受压；
短周期开始修复；
短周期跌破候选；
短周期突破候选。
```

但 4h 不得单独推翻 1d 大结构。

## 6. 多头结构状态

### 6.1 多头结构保持

含义：

```text
上涨结构仍然有效。
```

应该出现：

```text
价格仍在关键支撑上方；
回调没有跌破前一重要低点；
支撑区仍然有效；
高低点结构没有明显破坏；
4h 即使回调，也没有破坏 1d 大结构。
```

不表示：

```text
应该做多；
应该加仓；
一定会继续上涨。
```

### 6.2 多头高位结构受压

含义：

```text
上涨背景仍可能存在，但高位结构已经受到压力。
```

应该出现：

```text
价格处于高位或压力区附近；
多次冲高失败；
4h 结构开始走弱；
动能配合不足；
但 1d 关键支撑尚未确认破坏。
```

不表示：

```text
顶部已经确认；
熊市已经开始；
应该做空；
应该减仓。
```

### 6.3 多头结构破坏候选

含义：

```text
多头关键结构已经出现破坏迹象，但还没有完成确认。
```

应该出现：

```text
价格刚跌破关键支撑；
跌破发生在已收盘 K 线；
但尚未出现跌破后延续；
尚未出现反抽失败；
尚未确认原支撑转为压力。
```

不表示：

```text
多头结构已经完全失效；
空头趋势已经确认；
应该立即做空。
```

### 6.4 多头结构已破坏

含义：

```text
多头关键结构已经失效。
```

应该出现：

```text
价格跌破关键支撑后没有快速收回；
跌破后出现延续下跌；
反抽关键位失败；
原支撑开始表现为压力；
1d 大结构也不再支持多头保持。
```

不表示：

```text
必须开空；
必须平多；
一定进入长期熊市。
```

### 6.5 多头结构修复

含义：

```text
此前受压或破坏的多头结构重新被收复。
```

应该出现：

```text
跌破后重新收回关键支撑；
重新站回关键结构区；
回踩不再跌破；
原压力重新被突破或转化为支撑；
4h 修复逐步得到 1d 支持。
```

不表示：

```text
必须做多；
必须追涨；
牛市一定重新开始。
```

## 7. 空头结构状态

空头结构是多头结构的对称表达。

### 7.1 空头结构保持

含义：

```text
下跌结构仍然有效。
```

应该出现：

```text
价格仍在关键压力下方；
反弹没有突破前一重要高点；
压力区仍然有效；
高低点结构没有明显修复；
4h 即使反弹，也没有修复 1d 大结构。
```

### 7.2 空头低位结构受压

含义：

```text
下跌背景仍可能存在，但低位空头结构已经受到修复压力。
```

应该出现：

```text
价格处于低位或支撑区附近；
多次下跌失败；
4h 结构开始转强；
下跌动能衰竭；
但 1d 关键压力尚未确认突破。
```

不表示：

```text
底部已经确认；
牛市已经开始；
应该做多；
应该加仓。
```

### 7.3 空头结构修复候选

含义：

```text
空头关键结构已经出现被修复的迹象，但还没有完成确认。
```

应该出现：

```text
价格刚突破关键压力；
突破发生在已收盘 K 线；
但尚未出现突破后延续；
尚未出现回踩确认；
尚未确认原压力转为支撑。
```

### 7.4 空头结构已修复

含义：

```text
空头关键结构已经失效。
```

应该出现：

```text
价格突破关键压力后没有快速跌回；
突破后出现延续上涨；
回踩关键位有效；
原压力开始表现为支撑；
1d 大结构也不再支持空头保持。
```

不表示：

```text
必须开多；
必须平空；
一定进入长期牛市。
```

### 7.5 空头结构重新转弱

含义：

```text
此前受压或修复候选的空头结构重新恢复下跌压力。
```

应该出现：

```text
突破压力失败后重新跌回区间；
反弹无法站稳关键压力；
回抽压力失败；
原压力继续有效；
4h 修复失败，并重新与 1d 空头结构一致。
```

## 8. 支撑压力角色转换

v2 应为后续版本预留“支撑压力角色转换”表达。

常见结构事实包括：

```text
原支撑跌破后变成压力；
原压力突破后变成支撑；
跌破后快速收回，说明跌破可靠性不足；
突破后快速跌回，说明突破可靠性不足；
跌破后反抽失败，增强结构已破坏证据；
突破后回踩有效，增强结构已修复证据。
```

这些仍然只是结构事实。

不得写成：

```text
跌破支撑后应该做空；
突破压力后应该做多；
反抽失败后应该加仓；
回踩有效后应该追多。
```

## 10. evidence_text_zh 要求

v2 的中文证据说明应解释“从位置事实到结构语义”的过程。

示例：

```text
1d 大结构仍在 74000~76000 支撑区上方，说明大结构尚未确认破坏；但 4h 小结构已经跌破 78000~79000 小支撑区，短周期结构走弱。因此本周期记录为多头结构破坏候选，而不是多头结构已破坏。
```

如果存在历史大结构参考位，证据说明可以追加：

```text
同时，720 天历史大结构参考位位于 56850~73300，当前价格接近该区域，且该区域更像长周期支撑；这只提示下方存在长期结构参考，不改变本周期结构方向，也不生成交易动作。
```

另一个示例：

```text
价格处于 1d 高位压力区下方，多次冲高未能站上压力区，4h 小结构也开始转弱；但 1d 关键支撑尚未跌破。因此本周期记录为多头高位结构受压，不等于顶部已经确认。
```

禁止写成：

```text
这里应该开空；
这里应该减仓；
这里应该等待回调结束；
这里应该追多。
```

## 11. 与 MarketRegime 的关系

MarketRegime 可以消费 Structure v2 输出的结构语义。

例如：

```text
market_context = 大背景偏多；
trend = 1d 偏多但 4h 转弱；
momentum = 推动力减弱；
structure = 多头高位结构受压；
```

MarketRegime 可以据此输出：

```text
多头高位结构受压环境。
```

但 Structure v2 不得自己输出 MarketRegime。

Structure v2 不得判断：

```text
这是牛市回调；
这是熊市开始；
这是熊市反弹；
这是牛市开始。
```

这些属于 MarketRegime 的综合判断。

## 12. 与 StrategyDefinition 的关系

StrategyDefinition 可以消费 Structure v2 的结构事实。

例如：

```text
多头回调支撑策略可以使用“多头结构保持 / 多头结构修复”；
空头反弹压力策略可以使用“空头结构保持 / 空头结构重新转弱”；
不交易策略可以使用“结构破坏候选 / 结构修复候选”作为观望原因；
空仓策略可以使用“结构已破坏 / 结构已修复”作为客观输入之一。
```

但 StrategyDefinition 不得绕过 Structure v2 自行重算结构事实。

如果策略需要新的结构事实，应先补充 Feature / AtomicSignal / DomainSignal 需求。

## 13. 验收重点

Structure v2 验收时，不看策略收益，不看是否开单。

只看：

```text
支撑压力事实是否仍然保留；
结构语义是否能从支撑压力、突破、跌破、收回、反抽失败中解释出来；
是否把普通回调误判为结构破坏；
是否把高位受压误写成顶部确认；
```
